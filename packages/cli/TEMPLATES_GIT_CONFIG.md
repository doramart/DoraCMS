# Templates Directory Git Configuration

## Overview
The `templates/` directory is a **build artifact** and should NOT be committed to Git. It is generated by the build script and should be regenerated on each build.

## Configuration

### .gitignore Entry
Added `templates/` to `packages/cli/.gitignore`:

```gitignore
# Build output
dist/
templates/
```

### Why templates/ Should Not Be Committed

1. **Build Artifact**: The `templates/` directory is generated by `scripts/build-templates.js` from the source code in `../../server/`, `../../client/`, etc.

2. **Large Size**: The templates directory contains ~1,233 files and ~27.57 MB of code, which would bloat the repository unnecessarily.

3. **Source of Truth**: The actual source code lives in the monorepo root (`server/`, `client/`). The templates are just a filtered copy for distribution.

4. **Reproducibility**: Anyone can regenerate the templates by running:
   ```bash
   pnpm run build:templates
   ```

5. **Security**: Keeping templates out of Git reduces the risk of accidentally committing sensitive files that might slip through the exclusion filters.

## Build Process

### Local Development
```bash
# Build templates from source
pnpm run build:templates

# Verify templates were built correctly
pnpm run verify:templates
```

### CI/CD Pipeline
The build pipeline should:
1. Install dependencies: `pnpm install`
2. Build templates: `pnpm run build:templates`
3. Build CLI: `pnpm run build`
4. Publish package: `pnpm publish`

The published npm package will include the `templates/` directory because it's listed in the `files` field of `package.json`:

```json
{
  "files": [
    "dist",
    "templates",
    "README.md",
    "LICENSE"
  ]
}
```

## Verification

### Check if templates/ is tracked
```bash
git ls-files packages/cli/templates/
```
Should return empty (no files tracked).

### Check git status
```bash
git status packages/cli/templates/
```
Should show "nothing to commit" or not mention templates at all.

### Verify .gitignore is working
```bash
# Create a test file in templates
touch packages/cli/templates/test.txt

# Check if git sees it
git status packages/cli/templates/test.txt
```
Should show "nothing to commit" - the file is ignored.

## Important Notes

1. **Never commit templates/**: If you see `templates/` in `git status`, something is wrong with the `.gitignore` configuration.

2. **Always rebuild before publishing**: Run `pnpm run build:templates` before publishing to ensure the latest code is included.

3. **CI/CD must build templates**: Your CI/CD pipeline must run the build script before publishing the package.

4. **Local testing**: Developers need to run `pnpm run build:templates` after cloning the repo to test the CLI locally.
